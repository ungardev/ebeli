# Ébeli — Iluminación LED Premium

Sitio web oficial de Ébeli, iluminación LED de alta ingeniería para proyectos residenciales, comerciales e industriales en Venezuela.

## Tech Stack

- Astro 6.1.8
- Tailwind CSS
- Manrope (self-hosted font)
- Vercel (deployment)

## Secciones

- Homepage (Hero, Stats, Instagram Feed, CTA WhatsApp)
- Catálogo de Productos (21 productos)
- Contacto
- Distribuidor

## Scripts

- `npm run dev` — Desarrollo local
- `npm run build` — Build para producción
- `npm run preview` — Preview del build

## Estructura del Proyecto

```
src/
  components/    # Componentes Astro
  layouts/        # Layouts base
  pages/          # Páginas del sitio
  content/        # Productos (markdown)
  data_files/     # Constantes y datos
  assets/styles/  # Estilos CSS

public/
  images/         # Imágenes de productos
  fonts/          # Fuentes self-hosted
  js/             # Scripts JavaScript
```
